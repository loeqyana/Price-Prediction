# 💻 Laptop Price Prediction

A machine learning web application built with Streamlit to predict laptop prices based on their specifications.

## 🚀 Demo

https://your-streamlit-link.streamlit.app

## 🔗 Repository

https://github.com/loeqyana/Price-Prediction.git

## 📌 Features

- Predict laptop prices
- Interactive Streamlit interface
- Price displayed in Euro and Indonesian Rupiah
- Supports various laptop brands and specifications

## 🛠️ Technologies

- Python
- Streamlit
- XGBoost
- Scikit-Learn
- Pandas
- NumPy

## 📂 Project Structure

```
.
├── app.py
├── XGB_submit.pkl
├── requirements.txt
├── README.md
```

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/loeqyana/Price-Prediction.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

## 📊 Machine Learning Model

Model used:
- XGBoost Regressor

Target:
- Laptop Price (Euro)
